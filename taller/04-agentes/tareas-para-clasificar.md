# ¿Prompt, Skill, agente o subagentes?

En parejas, decidan qué necesita cada tarea. Escriban una sola opción por tarea y una frase que justifique la elección.

| | Tarea | Opción | ¿Por qué? |
|---|---|---|---|
| a | Traducir al inglés el resumen de un artículo para un curso. | | |
| b | Redactar cada semana el acta de la reunión del grupo de estudio, siempre con el mismo formato. | | |
| c | Encontrar por qué falla el proyecto de programación: leer el código, ejecutar las pruebas y proponer el arreglo. | | |
| d | Comparar los planes de estudio de cinco universidades para un intercambio, cada uno con decenas de páginas. | | |
| e | Escribir un correo al profesor para pedir una prórroga. | | |
| f | Preparar las exposiciones de todas las materias del semestre con el mismo estilo. | | |

Opciones: **prompt**, **Skill**, **agente**, **subagentes**.

## Preguntas que ayudan a decidir

1. ¿Se hace una sola vez? → probablemente un **prompt**.
2. ¿Se repite igual, con el mismo formato o estilo? → una **Skill**.
3. ¿Exige varios pasos con herramientas (leer archivos, buscar, ejecutar código) y decisiones sobre la marcha? → un **agente**.
4. ¿Se divide en partes grandes e independientes que podrían hacerse en paralelo? → **subagentes**.
