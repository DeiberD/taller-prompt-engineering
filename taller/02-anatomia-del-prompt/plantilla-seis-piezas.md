# Plantilla de las seis piezas

Copia el bloque que prefieras, llénalo y pégalo en un chat nuevo. Borra las líneas que no apliquen.

## Versión en texto

```text
ROL:           Actúa como…
CONTEXTO:      Esto es para… La audiencia es… Ya tengo…
TAREA:         Necesito que…
FORMATO:       Entrégalo como…
RESTRICCIONES: No… Máximo… Si no sabes algo, dilo.
EJEMPLOS:      Así se ve algo bien hecho: …
```

## Versión con etiquetas XML

```xml
<rol>
Actúa como…
</rol>

<contexto>
Esto es para…
La audiencia es…
Ya tengo…
</contexto>

<tarea>
Necesito que…
</tarea>

<formato>
Entrégalo como…
</formato>

<restricciones>
- No…
- Máximo…
- Si no sabes algo o no estás seguro, dilo en lugar de inventarlo.
</restricciones>

<ejemplos>
<ejemplo>
…
</ejemplo>
</ejemplos>
```

## Preguntas para llenar cada pieza

| Pieza | Pregúntate |
|---|---|
| Rol | ¿Qué experto haría esto mejor? ¿Con qué experiencia? |
| Contexto | ¿Quién va a leer o usar el resultado? ¿Para qué? ¿Qué sabe ya? ¿Qué materiales tengo? |
| Tarea | ¿Cuál es el verbo (escribe, resume, compara, corrige, explica)? ¿Cuál es el entregable? |
| Formato | ¿Extensión? ¿Secciones? ¿Tabla, lista, párrafos, código? ¿En qué idioma? |
| Restricciones | ¿Qué no debe hacer? ¿Qué límites de longitud, nivel o tono hay? |
| Ejemplos | ¿Tengo algo propio que muestre el estilo o el nivel que quiero? |

## Frases útiles para las restricciones

- «Si no estás seguro de un dato, dilo explícitamente en lugar de inventarlo.»
- «No inventes referencias. Si citas una fuente, debe ser real y verificable.»
- «Antes de responder, hazme las preguntas que necesites para hacerlo bien.»
- «Usa un tono cercano, como si se lo explicaras a un compañero.»
- «Si mi pedido es ambiguo, dime cuál interpretación tomaste.»
